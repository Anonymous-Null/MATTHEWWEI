Connect your computer and phone

This is a one-time setup. Your existing dashboard entries stay in your browser. Connect the computer that has your history first.

  1. Create a free Supabase project. Open Supabase, sign in with GitHub, and create a project. A name such as “Matthew dashboard” is fine. Save the database password in your password manager; the dashboard does not need it. Wait until the project is ready.
  2. Set the website address. In Supabase, open Authentication → URL Configuration. Set Site URL to https://anonymous-null.github.io/MATTHEWWEI/. Add that same address under Redirect URLs, and save. This makes confirmation and password-reset emails return to your dashboard.
  3. Create the private save table. In Supabase, open SQL Editor → New query. Copy the setup below, paste it into the editor, and click Run. The script creates a table and account access rules; each signed-in account can read and change only its own row.

  4. Connect the dashboard. Find your Project URL under Supabase Project Settings → Data API (or the project’s Connect dialog). Under Project Settings → API Keys, copy the publishable key, beginning sb_publishable_. The legacy anon key also works. On the dashboard, open Settings → Sync your devices → Connect the save service. Paste those two values and press Connect project.These are browser-safe public connection values. Do not enter a secret key, service_role key, database password, or GitHub token.
  5. Create your dashboard account on the computer. In that same section, enter your email and a new password, and press Create account. This account is for your dashboard, separate from the Supabase management login. Confirm the email, then sign in. Wait for “Synced across your devices.” Your current tasks and history will be included.
  6. Connect your phone. Press Connect another device on the computer. Send the copied setup link to your phone with AirDrop, Messages, or your preferred method. Open it in Safari or Chrome, then sign in with the same dashboard email and password. The setup link includes only the public connection values; it contains no password, login token, or personal logs.

How saving works

Changes sync automatically while the dashboard is open, about every 15 seconds, when you reopen it, and after your connection returns. Offline edits remain on the device until then. Checkmarks are stored by their original morning/evening check-in, so the 7 AM and 7 PM reset does not remove history.

Separate tasks and logs merge. Deleted items stay deleted when an older device reconnects. If two devices edit the same item before syncing, its version timestamp resolves the conflict, with the device identifier breaking ties. For a long note, finish on one device and let it sync before editing it on the other. A backup of this browser’s entries is kept before its first sync and can be downloaded in Settings.

The website and sync do not require ChatGPT Plus. Sync depends on your Supabase project remaining available. The dashboard still saves locally if the online service is temporarily unavailable.
